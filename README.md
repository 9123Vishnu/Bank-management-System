# 🏦 Bank Management System (Java Console Project)

A beginner-friendly **Bank Management System** built using **Core Java** following clean object-oriented design principles.  
This project simulates basic banking operations such as account creation, deposit, withdrawal, transfer, and balance inquiry through a console-based menu system.

---

## 📌 Features

✅ Create New Bank Account  
✅ Deposit Money  
✅ Withdraw Money  
✅ Transfer Funds Between Accounts  
✅ Check Account Details & Balance  
✅ Input Validation using Exception Handling  
✅ Unique Random Account Number Generation  
✅ Clean Layered Architecture

---

## 🛠️ Tech Stack

- Core Java
- OOP Concepts
- Collections (`HashMap`)
- Exception Handling
- Console Application

---

## 🧠 Concepts Used

- Encapsulation  
- Abstraction  
- Classes & Objects  
- Constructors  
- Access Modifiers  
- `HashMap` for in-memory storage  
- `Scanner` for user input  
- `Random` for account generation  
- `InputMismatchException`
